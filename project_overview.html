项目概览

LeRobot 是 Hugging Face 开发的开源机器人学习框架，旨在为真实世界机器人技术提供模型、数据集和工具。通过降低门槛，让所有人都能贡献和受益于共享数据集与预训练模型。

💾 数据集

LeRobotDataset 格式

LeRobotDataset 是标准化的机器人数据集格式，采用 Parquet + MP4 的混合存储方案：

  • Parquet文件 - 存储状态、动作、时间戳等结构化数据
  • MP4视频 - 存储视觉观测数据，支持高效流式传输

数据集结构

dataset/ ├── meta/ │ ├── info.json # 数据集元信息 │ ├── episodes.jsonl # 剧集列表 │ ├── stats/ # 统计数据 │ │ ├── action.json │ │ └── observation.json │ └── tasks.jsonl # 任务描述 ├── data/ │ └── chunk_000/ │ └── episode_00000.parquet ├── videos/ │ └── chunk_000/ │ └── camera_0/ │ └── episode_00000.mp4 └── images/ # 可选：原始图像帧 └── camera_0/ └── episode_00000/ └── frame_000000.png

安装

  1. 安装核心库
    pip install lerobot
  2. 安装额外功能（按需）
    # 安装所有功能 pip install 'lerobot[all]' # 或按需安装 pip install 'lerobot[dataset,training]' pip install 'lerobot[so100,feetech]' # 硬件支持 pip install 'lerobot[act,diffusion]' # 策略网络
  3. 验证安装
    lerobot-info

常用命令

# 录制数据 lerobot-record --robot.type=so100_follower --repo-id=my-dataset # 训练策略 lerobot-train --policy=act --dataset.repo_id=lerobot/aloha_mobile_cabinet # 评估策略 lerobot-eval --policy.path=lerobot/act_aloha --env.type=aloha # 遥操作 lerobot-teleoperate --robot.type=so100_follower # 校准机器人 lerobot-calibrate --robot.type=so100_follower
